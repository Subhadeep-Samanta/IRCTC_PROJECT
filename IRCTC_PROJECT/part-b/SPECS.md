# Feature Specifications — Part B

## Feature 1: Tatkal Smart Queue

Problem:
Tatkal booking failures during peak traffic.

Solution:
Introduce a live queue system displaying queue position and estimated waiting time.

Success Metrics:
- Reduced booking abandonment.
- Reduced refresh attempts.
- Improved user satisfaction.

---

## Feature 2: Persistent Search Filters

Problem:
Search filters reset unexpectedly.

Solution:
Store filter selections until user changes them.

Success Metrics:
- Reduced repeated filtering.
- Faster train discovery.

---

## Feature 3: Reliable Berth Preference Storage

Problem:
Seat preferences reset.

Solution:
Persist berth selections across all booking screens.

Success Metrics:
- Reduced preference-related complaints.

---

## Feature 4: Quick Access PNR Search

Problem:
PNR status difficult to discover.

Solution:
Place PNR search prominently on homepage.

---

## Feature 5: Mobile Booking Optimization

Problem:
Excessive scrolling on mobile.

Solution:
Multi-step mobile booking form.

---

## Feature 6: Refund Visibility Enhancement

Problem:
Refund details unclear.

Solution:
Display expected refund before cancellation confirmation.
